# Edible Atlas FoodSeq: Global Food Explorer

The public copy of the FoodSeq site at https://map.edibleatlas.org: a searchable map of foods people eat, built from published
studies, and the FoodSeq reference sequences (trnL for plants, 12SV5 for animals) used to identify foods from DNA.

This repository only holds the published site (`index.html`, `assets/`, `data/`, `downloads/`). It is generated from
the Edible Atlas lab's private working repository, so please do not edit it by hand.

* **Food records** come from published sources whose licences allow reuse with attribution (CC BY, CC0 or public
  domain). Each record names its source; please credit it. The records are general information, not nutrition or
  food-safety advice. The source list is in `downloads/foodseq-global-foods-sources.csv`.
* **Reference sequences** are released under CC BY 4.0. Citation and release notes are in `downloads/README.md`.
* **Pipeline code** for the reference database: https://github.com/LAD-LAB/food-dbs
* **Contact:** https://edibleatlas.org/contact
